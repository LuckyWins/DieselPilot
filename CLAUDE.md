# Контекст проекта

Форк PPTG/DieselPilot — ESP32-контроллер для китайского дизельного
отопителя через 433 МГц (CC1101).

Параметры конкретной установки — железо, условия в гараже —
в CLAUDE.local.md (не коммитится).

Управление: Web GUI только в локальной сети, удалённо — Telegram-бот.
Код MQTT в проекте сохранён, но выключен и инертен: это путь к Home
Assistant, если он когда-нибудь понадобится.

## Правила
- Не менять протокол CC1101 и логику парковки без явной просьбы
- Сборка: pio run / pio run -t uploadfs (или make build / make fs)
- Тесты: make test — чистая логика, гоняется на хосте без железа
- Отложенные задачи и обоснования отклонённых вариантов — в TODO.md
- Комментарии в коде — только на английском (включая тесты, platformio.ini, Makefile)
- Коммиты, документация в репозитории (TODO.md) и общение — на русском
